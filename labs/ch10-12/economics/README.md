# Economics teaching worksheet

`illustrative_economics.py` checks the numerical examples used in Chapters 10 and 11. It runs locally without third-party packages or network access. Execute it with an available Python 3.10+ runtime. It prints JSON to standard output and does not modify the historical evidence.

The `illustrative` object uses invented inputs to demonstrate assigned labor cost, marginal savings, sensitivity to review time, amortization, retry break-even, and elapsed versus aggregate parallel stage time. The currency values are not current prices or Northstar measurements. Assertions reject discrepancies in the numerical examples.

The `historical` object reads the real retained `companion/experiments/run-01/result.json` and `invocation.json`, preserving unknown human attention, review corrections, and monetary cost as null. A completed process is not a substitute for independent application acceptance.

All five controlled comparison arms in Chapter 11.13 remain proposed and unmeasured. This calculator does not execute an agent, generate a human baseline, or establish performance superiority. It only verifies arithmetic and transcribes the existing pilot record.
